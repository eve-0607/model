# Eve Master Plan

## Phase 0 — Reproduction
TASK-000..002. Establish a reproducible reference for the supplied BF16 teacher and audit the real checkpoint.

## Phase 1 — Architecture
TASK-003..007. Implement Eve's target sparse topology, checkpoint surgery, routing, correctness, and distributed execution.

## Phase 2 — Recovery
TASK-008. Recover the modified model on licensed/generic capability data.

## Phase 3 — Distillation
TASK-009..012. Build teacher generation, white-box KD, distillation training, and MTP.

## Phase 4 — Personalization
TASK-013..018. Parse and sanitize the private export, extract corrections/preferences, generate teacher-refined examples, perform SFT and preference optimization.

## Phase 5 — Evidence
TASK-019..021. Build evaluation, test no-system-prompt persistence, and run architecture ablations.

## Phase 6 — Memory / Inference
TASK-022..024. Conditional memory, auxiliary teacher/merge experiments, and Eve-Draft.

## Phase 7 — Release
TASK-025. Produce a reproducible demo and research package.

### Research discipline
Every major claim must be tied to an experiment. Every external architectural idea has provenance. Every private-data transformation is reproducible without committing raw private data.
