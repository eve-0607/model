# Repository Proofread — 2026-10-02

## Findings

### Fixed
1. The src-layout package lacked explicit setuptools package discovery, so a fresh editable install could fail to expose the eve package.
2. The task files after TASK-006 were too generic to safely drive an autonomous coding agent.
3. The plan did not define separate accounting for neural active parameters versus conditional-memory parameters.
4. The distillation spec did not explicitly state the shared-tokenizer requirement for direct logit KD.
5. MTP and speculative drafting were conflated too loosely. They are now separated.
6. Distributed compatibility was underspecified; the plan now requires feature-combination checks.
7. The private-data rules did not explicitly prevent raw export/log leakage.
8. The Qwen note did not identify that the current source is multimodal; TASK-001 now inventories modality components before Eve v1 scope is frozen.
9. The architecture-surgery path lacked a dedicated function-preserving/model-upcycling research note.
10. The evaluation plan did not define how the fixed-prompt personalization baseline is constructed or how leakage is prevented.
11. The repository ignored some large/private archive formats; .zip and .7z are now excluded.
